# 图 4：不同时刻整龙位置分布

本图展示问题一在 `0, 60, 120, 180, 240, 300 s` 六个典型时刻的全部
224 个把手中心位置，用于直观比较板凳龙逐步盘入的空间分布。

## 数据源

默认依次查找：

```text
提交\result1.xlsx
建模计算\问题1\输出\result1.xlsx
```

赛题附件目录中的同名文件是空模板，不能作为本图数据源。脚本会检查六个时间列、
224 个节点及相邻把手定长约束。

## 运行

```powershell
python ".\图片存放\问题1\图04_典型时刻整龙位置分布\生成图片.py"
```

也可显式指定结果文件：

```powershell
python ".\图片存放\问题1\图04_典型时刻整龙位置分布\生成图片.py" --input "C:\path\to\result1.xlsx"
```

输出 PNG（300 dpi）、SVG 和 PDF。

建议放置在问题一“计算结果与分析”部分的典型位置结果表之后，图名为：

> 图 4 不同时刻整条板凳龙的位置分布
