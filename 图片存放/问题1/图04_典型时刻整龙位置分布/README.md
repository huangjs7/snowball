# 图 4：典型时刻整龙位置分布

本图展示问题一在 `0, 60, 120, 180, 240, 300 s` 六个典型时刻的全部
224 个把手中心位置，用于直观比较板凳龙逐步盘入的空间分布。建议放在问题一
“计算结果与分析”中典型位置结果表之后。

## 数据源

脚本默认依次查找仓库内的以下填充结果：

```text
提交\result1.xlsx
建模计算\问题1\输出\result1.xlsx
```

赛题附件目录中的同名文件是空模板，不能作为本图数据源。当前推荐图使用任务提供的
仓库外结果文件 `..\result1.xlsx` 生成，其 SHA-256 为
`307D134B41DD28AA90171417DE1AEA22CD43F2951A6F509D7C1091D1629EAB18`。

读取“位置”工作表中的六个典型时刻列；每一列按 224 个把手中心的
`x, y` 坐标成对读取。脚本会检查时间列、节点数、有限数值、初始 A 点、节点由
龙头向龙尾的向外顺序，以及相邻把手定长约束。

图中浅蓝色曲线是完整的阿基米德螺线，深蓝色圆点是把手中心；深蓝色直线段按
龙头板 `3.41 m`、龙身和龙尾板 `2.20 m` 的实际长度绘制。红色、紫色外圈分别
突出龙头前把手和龙尾后把手，但把手本体仍保持深蓝色。

## 已完成检查

- 六个面板使用相同坐标范围和等比例坐标轴；
- 每个面板包含 224 个把手中心，并突出龙头前把手、龙尾后把手与螺线中心；
- `t=0` 龙头前把手位于第 16 圈 A 点：`theta=32*pi, r=8.8 m`，龙身从 A
  点向外排列；
- 首段把手中心弦长为 `2.86 m`，其余为 `1.65 m`；当前数据的最大误差为
  `4.060e-12 m`；
- 六个典型时刻均满足 `板凳实长 L > 螺线弧长 s > 直线弦长 d`；其中
  `min(s-d)=1.321e-3 m`，`min(L-s)=5.098e-1 m`；
- 已从仓库根目录成功生成同名 PNG、SVG、PDF，且未向其他目录写入成图；
- 画布按 A4 论文约 `16 cm` 版心宽度校准，缩放后图中文字仍可辨认。
