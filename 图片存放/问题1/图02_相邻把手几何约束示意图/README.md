# 图 2：相邻把手几何约束示意图

## 用途

用于问题一“各把手位置的递推模型”，说明相邻把手中心位于同一条阿基米德
螺线上，同时满足固定直线弦长约束。论文中建议置于定长约束公式之后。

## 参数与数据来源

- 螺距：题目给定的 $p=0.55\,\mathrm{m}$，故 $b=p/(2\pi)$；
- 图中选取一节龙身（或龙尾）板凳，固定把手间距 $d_i=1.65\,\mathrm{m}$；
- 龙头把手间距为 $d_0=2.86\,\mathrm{m}$；
- 本图为解析几何示意图，不读取外部结果文件。
