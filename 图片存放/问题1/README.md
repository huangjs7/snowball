`common_plotting.py` 保存统一配色、数学参数和公共几何函数。请从各图目录运行
`生成图片.py`，输出会写回同一目录。

需要一次重绘图 1～3 时，可从仓库根目录运行：

```powershell
python ".\图片存放\问题1\common_plotting.py"
```
