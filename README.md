c:\Users\ASUS\Desktop\数学建模\提示词\提示词.txt# 数学建模竞赛协作仓库

仓库按三人分工管理：一人负责建模计算，一人负责配图，一人负责论文。只保留当前有实际内容的目录，不预建空的问题目录。

## 当前目录

| 目录 | 负责人 | 内容 |
| --- | --- | --- |
| `赛题+资料/` | 全员只读为主 | 当前赛题、官方附件、历史资料和原始论文模板 |
| `图片存放/` | 绘图负责人 | 各问题的单图目录、生成脚本和成图 |
| `论文/` | 论文负责人 | 唯一主稿 `主稿.tex` |
| `提示词/` | 全员 | 可交给其他 Agent 的任务提示词 |
| `交接文档/` | 全员 | 跨负责人结论、待办和版本说明 |

当前没有模型文档、计算代码或计算结果，因此不保留空的 `模型/`、`代码/`、`结果/`。

## 新建建模计算内容

程序负责人开始某一问后，按需建立：

```text
建模计算/
└── 问题N/
    ├── README.md       # 假设、符号、公式、参数、结论和运行方法
    ├── solve.py        # 主运行入口
    ├── 其他模块.py
    └── 输出/           # 本问生成的中间结果
```

同一问的模型、代码和输出放在一起。确认提交的文件从 `输出/` 移至根目录 `提交/`，不要保留两份同名结果。

## 开始工作

1. 阅读 `AGENTS.md`、负责目录的 README 和最新交接记录。
2. 从自己的功能分支开始，只修改职责范围内的文件。
3. 运行相关脚本，核对输出位置，再检查 `git status --short`。
4. 需要其他成员跟进时，在 `交接文档/` 新建记录。

图片的续作与生成文件管理规则见 [图片存放/README.md](图片存放/README.md)。论文原始模板位于 `赛题+资料/论文模板/`，不能覆盖当前主稿。
